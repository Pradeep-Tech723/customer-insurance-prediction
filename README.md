# 🛡️ Customer Insurance Prediction Using Machine Learning

## 📌 Project Overview

Customer Insurance Prediction is a Machine Learning-based web application designed to predict whether a customer is likely to purchase insurance based on their **Age** and **Estimated Salary**.

The project combines Machine Learning with a **Flask web application** to provide a simple and interactive platform where users can enter customer details and receive an instant prediction.

## 🎯 Objective

The main objective of this project is to develop an intelligent prediction system that can analyze customer information and predict their likelihood of purchasing insurance.

This project demonstrates an end-to-end Machine Learning workflow, from data preprocessing and model training to deploying the trained model through a web interface.

## 🧠 Machine Learning

The system uses customer attributes such as:

* **Age**
* **Estimated Salary**

The target variable is **Purchased**, which indicates whether the customer purchased insurance.

The Machine Learning workflow includes:

1. Loading the dataset
2. Data preprocessing
3. Splitting data into training and testing sets
4. Feature scaling
5. Training Machine Learning models
6. Evaluating model performance
7. Selecting the trained model
8. Saving the model
9. Integrating the model with Flask
10. Generating predictions through the website

## 📊 Prediction

The application accepts customer details through the web interface and sends the information to the trained Machine Learning model.

The model then predicts whether the customer is likely to purchase insurance.

### Prediction Output

* **Purchased = 1:** Customer is predicted to purchase insurance
* **Purchased = 0:** Customer is predicted not to purchase insurance

The Flask web application provides an easy-to-use interface where users can enter:
